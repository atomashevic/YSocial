Quick Reference Guide

Feed Limits
These settings control how much content is retrieved from external sources during simulation.

Higher limits mean more variety but slower ingestion.
Lower limits mean faster startup but less content diversity.

RSS vs Reddit JSON API
Standard RSS feeds are usually limited to a small number of entries.

The Reddit JSON API supports pagination and can retrieve much larger batches.

Recommended Values
Small simulations: 50-100 entries
Medium simulations: 100-200 entries
Large simulations: 200-500 entries

Rate Limiting
Reddit may block requests if the rate limit is too low. A value of 2+ seconds is the safe default.
